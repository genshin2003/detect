## 一、项目整体架构

### 1.1 系统架构概述

本项目采用**前后端分离 + 双后端**架构，由三个独立模块组成：

```
┌─────────────────┐     HTTP/WebSocket      ┌──────────────────────┐     HTTP      ┌──────────────────────┐
│   Vue3 前端      │ ◄──────────────────────► │  SpringBoot 后端      │ ◄────────────► │  Flask 推理后端       │
│  (端口 3000)     │                          │  (端口 9999)          │               │  (端口 5000)          │
│  Element Plus    │                          │  MyBatis-Plus         │               │  YOLO (ultralytics)  │
│  Pinia           │                          │  JWT 认证             │               │  LangChain AI        │
│  ECharts         │                          │  WebSocket            │               │  Socket.IO           │
└─────────────────┘                          └──────────────────────┘               └──────────────────────┘
                                                    │
                                                    ▼
                                            ┌──────────────┐
                                            │   MySQL 数据库  │
                                            │  (端口 3306)   │
                                            │  yolo_detect   │
                                            └──────────────┘
```

### 1.2 通信流程

- **前端 → SpringBoot**：前端所有请求先经过 SpringBoot（端口9999），通过 Axios 发送 HTTP 请求，请求头携带 JWT Token
- **SpringBoot → Flask**：SpringBoot 通过 `RestTemplate` 将推理请求转发到 Flask（端口5000），同时透传 Authorization Token
- **Flask → SpringBoot**：Flask 推理完成后，通过 `Fun.save_data()` 方法将视频/摄像头检测记录回传给 SpringBoot 保存到数据库；通过 `Fun.upload()` 将结果图片上传到 SpringBoot 的文件服务
- **Flask → 前端（WebSocket）**：Flask 通过 `flask-socketio` 向前端推送实时状态消息（如"处理完成，正在保存"、转码进度等）
- **SpringBoot → 前端（WebSocket）**：SpringBoot 通过原生 WebSocket（`/ws/message`）向前端推送消息通知

### 4.3 HTTP 请求封装（Axios 拦截器）

**文件**：`src/utils/request.ts`

创建 Axios 实例，配置如下：
- `baseURL`：从环境变量 `VITE_API_DOMAIN` 读取
- `timeout`：500000ms（500秒，因为推理可能耗时较长）

**请求拦截器**：
1. 判断请求体是否为 `FormData`，是则设置 `Content-Type: multipart/form-data`，否则设置 `Content-Type: application/json;charset=UTF-8`
2. 从 `Session.get('token')` 获取 Token（存储在 Cookie 中），设置到请求头 `Authorization` 字段

**响应拦截器**：
1. 如果响应体中 `code === 401` 或 `code === 4001`，清除浏览器缓存，跳转到登录页，弹出"你已被登出，请重新登录"提示
2. 网络超时显示"网络超时"，网络错误显示"网络连接错误"

### 4.4 Token 存储机制

**文件**：`src/utils/storage.ts`

Token 存储使用 **Cookies**（而非 sessionStorage），通过 `js-cookie` 库实现：
- `Session.set('token', val)` → `Cookies.set('token', val)`
- `Session.get('token')` → `Cookies.get('token')`
- `Session.clear()` → `Cookies.remove('token')` + 清空 sessionStorage

其他临时数据使用 `sessionStorage`，永久数据使用 `localStorage`。

### 4.5 登录注册功能

#### 4.5.1 登录流程

**文件**：`views/login/index.vue`

1. 用户在登录页输入用户名和密码
2. 前端表单校验：用户名3-10个字符，密码5-8个字符
3. 点击"登录"按钮，调用 `submitForm()` 方法
4. 发送 `POST /api/user/login` 请求，请求体 `{ username, password }`
5. 后端 `UserController.login()` 接收请求 → 调用 `UserService.login()`
6. `UserService.login()` 执行逻辑：
   - 通过 `userMapper.selectByName(username)` 查询用户
   - 将用户输入的密码进行 MD5 加密：`DigestUtils.md5DigestAsHex(password.getBytes())`
   - 与数据库中的密码比对
   - 匹配成功后，调用 `JwtUtils.createToken(userId, username, role)` 生成 JWT Token
   - Token 有效期 24 小时，密钥为 `crop_diseases_detection_secret_key_2026`
   - 将 Token 设置到 User 对象的 `token` 字段（非数据库字段，`@TableField(exist = false)`）
   - 清空密码字段后返回用户信息
7. 前端收到响应后：
   - 将 `role` 存入 Cookie：`Cookies.set('role', res.data.role)`
   - 调用 `onSignIn(res.data.token)` → 将 Token 存入 Cookie：`Session.set('token', token)`
   - 根据 `themeConfig.isRequestRoutes` 决定使用前端路由还是后端路由
   - 跳转到 `/home` 首页

#### 4.5.2 注册流程

1. 用户在注册页输入用户名、密码、确认密码、姓名等信息
2. 发送 `POST /api/user/register` 请求
3. 后端 `UserService.register()` 执行逻辑：
   - 检查用户名是否已存在
   - 密码进行 MD5 加密
   - 设置默认角色为 `common`，设置注册时间为当前时间
   - 插入数据库

#### 4.5.3 忘记密码流程

1. 登录页点击"忘记密码"，弹出对话框
2. 输入用户名、新密码、确认密码
3. 前端校验：两次密码一致
4. 发送 `PUT /api/user/password` 请求，携带 `{ username, password }`
5. 后端 `UserService.resetPassword()` 执行：
   - 查询用户是否存在
   - 新密码 MD5 加密后更新到数据库

### 4.6 JWT 认证机制

#### 4.6.1 Token 生成（JwtUtils）

**文件**：`common/JwtUtils.java`

```java
// 密钥：crop_diseases_detection_secret_key_2026
// 过期时间：24小时
// Claims 包含：userId, username, role
public static String createToken(Integer userId, String username, String role) {
    Map<String, Object> claims = new HashMap<>();
    claims.put("userId", userId);
    claims.put("username", username);
    claims.put("role", role);
    return Jwts.builder()
            .claims(claims)
            .subject(username)
            .issuedAt(new Date())
            .expiration(new Date(System.currentTimeMillis() + EXPIRE_TIME))
            .signWith(getSigningKey())  // HMAC-SHA 密钥
            .compact();
}
```

#### 4.6.2 Token 验证拦截器（JwtInterceptor）

**文件**：`common/JwtInterceptor.java`

拦截器在每个请求到达 Controller 之前执行 `preHandle()` 方法：
1. 获取请求头中的 `Authorization` 字段
2. 如果 Token 为空，返回 401
3. 调用 `JwtUtils.parseToken(token)` 解析并验证 Token
4. 如果 Token 无效或过期，返回 401
5. 验证通过后，将 `userId`、`username`、`role` 存入 `request.setAttribute()`，供后续 Controller 使用

#### 4.6.3 拦截器配置（WebConfig）

**文件**：`common/WebConfig.java`

```java
registry.addInterceptor(jwtInterceptor)
        .addPathPatterns("/**")           // 拦截所有请求
        .excludePathPatterns(              // 排除以下路径
            "/user/login",                 // 登录
            "/user/register",              // 注册
            "/user/resetPassword",         // 重置密码
            "/files/**",                   // 文件服务（图片直接访问不需要Token）
            "/ws/**"                       // WebSocket 连接
        );
```

#### 4.6.4 Flask 端 Token 验证

Flask 端也独立实现了 JWT 验证（使用 PyJWT 库），通过 `token_required` 装饰器保护所有推理接口：
- 从请求头 `Authorization` 或查询参数 `token` 获取 Token
- 使用相同的密钥 `crop_diseases_detection_secret_key_2026` 和 HS256 算法解码
- 验证失败返回 401

### 4.8 消息通知系统

#### 4.8.1 消息通知架构

消息通知系统由两套 WebSocket 组成：

1. **SpringBoot WebSocket**（`ws://localhost:9999/ws/message`）：用于消息通知推送
2. **Flask Socket.IO**（`http://localhost:5000`）：用于推理状态实时推送

#### 4.8.2 SpringBoot WebSocket 通信

**前端连接**（`src/utils/websocket.ts`）：

```typescript
class MessageSocket {
    connect() {
        const token = Session.get('token');
        const wsUrl = `ws://localhost:9999/ws/message?token=${token}`;
        this.socket = new WebSocket(wsUrl);
        // 连接关闭后5秒自动重连
    }
}
```

连接时通过 URL 查询参数传递 Token，后端 `MessageWebSocketHandler.afterConnectionEstablished()` 解析 Token 获取 userId，将 `userId → WebSocketSession` 映射存入 `ConcurrentHashMap`。

**消息接收处理**：
- 收到 `type: 'notification'` 消息时：
  - 调用 `messageStore.fetchUnreadCount()` 更新未读消息数
  - 根据 `messageType` 和 `priority` 设置通知样式：
    - `SECURITY` 类型 → `error` 通知，持续10秒
    - `HIGH` 优先级 → 紧急公告样式（红色），持续15秒
    - `BATCH_DETECT` 类型 → `success` 通知，持续6秒
    - `DETECT` 类型 → `success` 通知，持续5秒
    - 其他 → `info` 通知，持续5秒
  - 通过 `ElNotification` 在页面右上角弹出通知

**消息 Store**（`stores/message.ts`）：
- `fetchUnreadCount()`：调用 `GET /api/message/unreadCount` 获取未读数量
- `markAllAsRead()`：调用 `POST /api/message/readAll` 标记全部已读

**顶栏消息图标**（`layout/navBars/breadcrumb/user.vue`）：
- 顶栏右侧显示铃铛图标，带未读数量角标：`<el-badge :value="messageStore.unreadCount">`
- 点击跳转到消息中心页面
- 页面加载时连接 WebSocket，注册消息回调

#### 4.8.3 消息管理功能

**消息类型**：
- `ANNOUNCE`：公告通知
- `SECURITY`：安全通知
- `DETECT`：单张检测完成通知
- `BATCH_DETECT`：批量检测完成通知

**消息发布**（管理员功能）：
- 管理员在 `/messagePublish` 页面发布公告
- 可选择发送范围：全体用户或指定用户
- 调用 `POST /api/message/publish`，请求体包含 `{ title, content, type, priority, scope, usernames }`
- 后端 `MessageController.publish()` 处理：
  - 校验管理员权限
  - 全体发送：调用 `messageService.sendToAll()`，存储一条 `user_id=0` 的广播消息
  - 指定发送：调用 `messageService.sendToUsers()`，为每个用户创建独立消息
  - 发送时检查用户消息偏好设置（`shouldNotify()`），根据免打扰和通知类型开关决定是否推送

**消息已读机制**：
- 个人消息：直接更新 `message` 表的 `is_read` 字段
- 广播消息：在 `message_read_status` 表中插入记录，通过该表判断用户是否已读

**消息偏好设置**：
- 用户可在消息中心设置通知偏好
- 支持4种通知类型独立开关：检测通知、批量检测通知、公告通知、安全通知
- 支持免打扰模式，可设置结束时间
- 免打扰期间只推送安全通知

**消息统计**（管理员功能）：
- 消息总数、各类型消息数量和占比
- 广播公告的已读率计算：`已读记录数 / (公告数 × 用户数) × 100%`
- 管理员未读消息数

#### 4.8.4 Flask Socket.IO 通信

**前端连接**（`src/utils/socket.ts`）：

```typescript
export class SocketService {
    constructor() {
        this.socket = io('http://localhost:5000');
    }
    on(event: string, callback: Function) {
        // 包装回调，将 data.data 传入原回调
        const wrappedCallback = (data: any) => callback(data.data);
        this.socket.on(event, wrappedCallback);
    }
}
```

**使用场景**：

- `cameraPredict/index.vue`：摄像头检测页面监听相同事件

**Flask 端发送**：
- `self.socketio.emit('message', {'data': '处理完成，正在保存！'})`：发送状态消息
- `self.socketio.emit('progress', {'data': progress})`：发送视频转码进度（0-100）


```
  │
  ├─ 1. 用户上传图片 → el-upload 组件直接上传到 SpringBoot POST /files/upload
  │     └─ FileController.upload() 保存文件，返回文件URL

  │     ├─ 校验参数：图片链接非空、权重非空、文件格式为 jpg/png/jpeg
  │     ├─ 创建 HttpHeaders，透传 Authorization Token

  │     │   └─ 返回 Flask 响应给前端
  │
  ├─ 4. Flask predictImg()
  │     ├─ 从 JSON 请求体提取参数：username, weight, conf, startTime, inputImg, ai
  │     ├─ 调用 get_model(weight) 加载 YOLO 模型
  │     │   └─ 检查缓存 self.models[weight]，未加载则从 ./weights/{weight} 加载
  │     │   └─ 设置中文标签：model.model.names = self.CHINESE_LABELS
  │     ├─ 执行推理：model.predict(source=inputImg, conf=conf)

  │     │   └─ 返回 { status: 400, message: "该图片无法识别，请重新上传！" }
```

```
  │     ├─ 前端通过 <img> 标签接收 MJPEG 流实时显示
  │     ├─ 处理完成后（finally 块）：
  │     │   ├─ 释放 OpenCV 资源
  │     │   ├─ 通过 WebSocket 发送"处理完成，正在保存"
  │     │   ├─ 转码输出视频：AVI → MP4（通过 FFmpeg）
  │     │   ├─ 通过 WebSocket 推送转码进度（0-100%）
  │     │   ├─ 上传结果视频到 SpringBoot
  │     │   ├─ 回传记录到 SpringBoot：POST http://localhost:9999/videoRecords
  │     │   └─ 清理所有临时文件
  │
  └─ 4. 前端通过 Socket.IO 监听进度事件，显示进度条
```

### 5.5 摄像头检测流程

```
前端 cameraPredict/index.vue
  │
  ├─ 1. 用户选择模型和置信度阈值
  │
  ├─ 2. 点击"开始录制" → start()
  │     ├─ 构造查询参数
  │     └─ 设置 img 标签的 src 为 Flask 流地址：
  │         http://127.0.0.1:5000/predictCamera?{queryParams}
  │
  ├─ 3. Flask predictCamera()
  │     ├─ 通过 WebSocket 发送"正在加载，请稍等"
  │     ├─ 打开摄像头：cv2.VideoCapture(0)
  │     ├─ 设置分辨率：640x480
  │     ├─ 初始化 VideoWriter 录制视频
  │     ├─ 逐帧处理（与视频检测类似的 generate 生成器）：
  │     │   ├─ 从摄像头读取帧
  │     │   ├─ YOLO 推理 + 绘制检测框
  │     │   ├─ 写入录制视频
  │     │   └─ yield 返回 MJPEG 流
  │     ├─ 前端通过 <img> 标签实时显示摄像头画面
  │     └─ 录制结束后的处理与视频检测相同
  │
  ├─ 4. 点击"结束录制" → stop()
  │     └─ 发送 GET /flask/stopCamera → Flask 设置 self.recording = False
  │
  └─ 5. Flask 检测到 recording=False，退出循环，执行 finally 块保存视频
```

```python
def get_model(self, weight):
    model_path = f"./weights/{weight}"
    if not os.path.exists(model_path):
        raise FileNotFoundError(f"模型不存在: {model_path}")
    if weight not in self.models:
        self.models[weight] = YOLO(model_path)  # 首次加载并缓存
    return self.models[weight]
```

- 使用 `yield` 生成进度百分比（0-100），供调用方通过 WebSocket 推送给前端

## 十、部署与启动

### 10.1 启动顺序

1. **MySQL 数据库**：确保 MySQL 服务运行，`yolo_detect` 数据库已创建
2. **Flask 推理后端**：`cd CropDiseasesDetection_flask && python main.py`（端口5000）
3. **SpringBoot 后端**：运行 `Kcsj.java` 主类（端口9999）
4. **Vue 前端**：`cd CropDiseasesDetection_vue && npm run dev`（端口3000）

### 10.2 环境变量

Flask 的 `.env` 文件需要配置：
```
DASHSCOPE_API_KEY=你的阿里DashScope API Key
```

### 10.3 依赖安装

- **前端**：`npm install`
- **SpringBoot**：Maven 自动管理（`pom.xml`）
- **Flask**：`pip install -r requirements.txt`（需安装 ultralytics, flask, flask-socketio, langchain, opencv-python, pyjwt, python-dotenv, requests）
- **系统依赖**：FFmpeg（视频转码用）
